# ゆらぎ (yuragi-ime) — 見た目のテーマ

## アイコン: 手描きの「あ」

製品アイコンは、鉛筆で手描きした「あ」を写真から取り出して輪郭にしたもの。
フォントの輪郭は使っていない。

言語バーには英語・中国語・韓国語などの入力方式が並ぶので、ひと目で日本語用と分かること、
小さくても迷わず読めることをいちばんに置いた。

## アイコンの形

- 「あ」を枠いっぱいに大きく、まっすぐ置く。切らない、揺らさない、傾けない、飾りを足さない。
- 字は手描きの形そのまま。写真から輪郭を取るときに線を約 25% 太らせた。
  ほかに加えているのは拡大縮小と位置合わせだけ。
- 全サイズで同じ輪郭を使う（手描きなので太さ違いは作らない）。
  16・20・24px は、線がいちばんくっきり出る位置に画素単位で合わせてある。

## 見た目の決まりごと

| 項目 | 内容 |
|---|---|
| 色 | 墨 `#111111` と白 `#ffffff` の 2 色だけ。中間調・グラデーション・差し色は使わない |
| 字 | 手描きのひらがな 1 字（「あ」）。全サイズ同じ輪郭 |
| 字の扱い | 形を変えない。切らない、曲げない、ぼかさない、二重にしない |
| 余白 | 要素を足さない。字だけ（波線や水面の線は描かない） |
| 言葉 | 設定画面などの文言も、柔らかい和語を優先する（例: 「同時打鍵のゆるさ」） |

## ファイル

| ファイル | 用途 |
|---|---|
| `yuragi.ico` | **既定。明暗両用。** 墨の角丸台座に白い「あ」。明るいタスクバーでは台座ごと、暗いタスクバーでは白い字が見える |
| `yuragi-light.ico` | 明るいタスクバー専用（台座なし・墨の字）。暗い背景では見えない |
| `yuragi-dark.ico` | 暗いタスクバー専用（台座なし・白い字）。明るい背景では見えない |
| `src/yuragi*.svg` | 元データ。`<名前>.svg` が原図（64 単位、32px 以上に使用）、`<名前>-16px/20px/24px.svg` が画素合わせ版 |
| `src/glyph.json` | 字の輪郭（手描きの「あ」、全サイズ共通）。`build.py` が読む |
| `build.py` | 寸法表と字の輪郭から SVG・.ico・preview.png をまとめて生成（`python3 build.py`、Pillow のみ必要） |
| `preview.png` | 確認用。各アイコンを明るい背景／暗い背景に実寸と拡大で並べたもの |

各 .ico には 16 / 20 / 24 / 32 / 40 / 48 / 64 / 256 px が入っている
（表示倍率 100〜300% に対応。256 のみ PNG 圧縮、ほかは 32bit BMP + マスク）。

## 組み込みの目安

```rc
IDI_YURAGI        ICON "yuragi.ico"
IDI_YURAGI_LIGHT  ICON "yuragi-light.ico"
IDI_YURAGI_DARK   ICON "yuragi-dark.ico"
```

- プロファイル登録（`ITfInputProcessorProfileMgr::RegisterProfile` のアイコン指定）は固定の 1 枚なので、
  明暗両用の `yuragi.ico` を使う。これだけで条件は満たせる。
- 台座なしの 2 枚は任意。言語バー項目のアイコンを実行時に返す箇所で、
  タスクバーの明暗に応じて出し分けたい場合に使う。

## 形を変えたいとき

`build.py` 冒頭の寸法表（`SMALL` と `MASTER`）を直して実行し直す。
決めるのは字の高さ `h`、上端の位置 `top`、横の寄せ `gx` の 3 つだけ。
SVG と .ico は同じ表から出るので、片方だけずれることはない。

字の輪郭（`src/glyph.json`）は手描きの線から取ったもので、線の太さも含めて確定している。
寸法表を直すときも、輪郭には手を加えない。

## 字の輪郭の出どころ

「あ」の輪郭は手描き。フォントの輪郭は含まない。
