# 連接表の全0行へのペナルティ（2026-11-11）

`zero-connection-experiment-2026-11-11.md`（リポジトリの親ディレクトリ）の
推奨形を、`docs-and-eval-2026-11-10` / `cbe9ac2` を基点に実装した。
`load_lex()` のキャッシュ保存・読み込みとユーザー辞書適用の後、左品詞 RID の
連接行が全列0なら、その全列（列0の EOS も含む）を3000にする。
全0なのでこれは各連接への +3000 と同じ。デコーダは変更しない。
キャッシュは従来どおり無補正のまま保存する。

`ZERO_ROW_PENALTY=0` で無効化できる。未設定なら3000。
実験を再現するため、他の整数値も指定できる。環境変数は `load_lex()` の呼び出しごとに読む。
既に読み込まれた辞書には影響しない。

## 実装前の157エントリ確認

[全件一覧（TSV）](zero-row-entries.tsv) は無補正の Mozc 辞書を
`load_lex(user_lexicon=False)` で読み、全0行の RID を持つ全エントリを抽出したもの。
列は RID、`id.def` の品詞、読み、表記、LID、単語コスト。省略・重複除去はしていない。
140行・157エントリで報告書と一致した。BOS の行0は全0ではない。

全件の読み・表記・品詞を確認した。活用形や接尾辞だけを見て無効語とは判断しない。
たとえばラ変「あれ・ある・あら・あり」、助動詞「ず」、接尾辞「掛かれ・続け・忘れりゃ」、
「下・分」、非自立の「はず」、形容詞接尾辞「強けれ・早く・高き・臭え・辛え」、
接頭詞「第・約」は、文脈次第で正しく使える。「ま～す」「で～す」なども表現として存在する。
一方、旧字体や通常使わない活用、読みの異綴りも混在しているため、一律に禁止はしない。

手書き辞書71行あり、学習・LMなしで、適用前 P=0 と P=3000 の1-bestを
una（読み既知）と amb（左右あいまい）で比較した。
[文例と全出力（TSV）](zero-row-probes.tsv) に2組計284条件を記録した
（各組内で una / amb を比較。組間で重複する文例がある）。
ラ変の仮定・命令・未然・連用・体言接続、助動詞、接尾動詞の仮定縮約・命令、
形容詞接尾辞の仮定・縮約・文語・口語・未然・連用、接頭詞、数詞の後の「分」、
「管理下・支配下」、「はず」などを含めた。

| 読み | P=0 → P=3000（una / amb 共通） | 判断 |
|---|---|---|
| あればいい | あればいい → あればいい | 仮定の用例を維持 |
| そうであれ | そうであれ → そうであれ | 命令の用例を維持 |
| ありうるはなし | あり得る話 → ありうる話 | どちらも正しい表記。元の経路は RID=644 を使用 |
| やくひゃくにん | 約百人 → 約百人 | 元の RID=2630 を避けても同じ表記 |
| わすれりゃいい | 忘れりゃイイ → 忘れりゃイイ | RID=948 を使用したまま維持 |
| くそったらしけりゃ | クソったらしけりゃ → クソったらしけりゃ | RID=2372 を使用したまま維持 |

追加組の「なだかきひと」は una で「無高き人→名高き人」に改善した。
最初の組の「ねだかからぬ」は una で「ね高からぬ→根高からぬ」に変わったが、
元が正しい用例ではない。「はずがない」の amb は「はずえない→はずがない」に改善した。
変化した全出力は上記 TSV に残した。

**確認した範囲で、正しい変換を誤りに変える具体例は見つからなかったため、除外品詞は設けない。**
「あり得る」の漢字表記を維持する保証はしない。全157エントリの全用法を網羅した評価ではなく、
実在語が含まれることと、有限の文例で悪化を確認できなかったことを区別する。
評価外の正しい変換が壊れる具体例が今後得られた場合は、品詞単位の除外を検討する。

抽出を再現するときは `ZERO_ROW_PENALTY=0` を指定して辞書を読み、
`not any(lex.connect[rid * lex.pos_size:(rid + 1) * lex.pos_size])` で行を選び、
`lex.by_reading` の各エントリの `rid` を照合する。
文例の再実行には TSV の `reading` を使い、una は各文字の plain トークン、
amb は `run_mozc_eval.reverse_table(load_table())` の各文字のトークンを
`decode_tokens()` に渡す。環境変数を0 / 3000にしてそれぞれ辞書を読み直す。

## 検証

読み込みの単体テストでは、非全0行の不変、左 RID 方向、EOS への加算、
環境変数による無効化、繰り返し読み込みでの非累積、キャッシュ読み込み・強制再生成の
両経路で無補正のキャッシュを維持することを確認する。

手書き辞書あり・学習なし・LMなし・既定 P=3000 での結果:

| 評価 | 結果 | 実験値との比較 |
|---|---|---|
| Mozc command amb | 401/592 | 一致 |
| Mozc command una | 418/592 | 一致 |
| Mozc 読み / 表記 amb | 550/594 / 463/594 | 一致 |
| Mozc 読み / 表記 una | 594/594 / 500/594 | 一致 |
| AJIMEE una / amb / amb 読み一致 | 103/200 / 96/200 / 174/200 | 一致 |
| 回帰ゲート | 5/5 PASS | 一致 |

Mozc の物理行32「あれたしょうがっこうだ」は「荒れた小学校だ」、
491「だいせいか」は「大成果」、528「さそおう」は「誘おう」で、amb / una とも PASS。
una の528は従来から正解であり、今回新たに解消したものではない。
保存されていた実験結果 `/tmp/zx/` の P=3000 とも照合し、Mozc の行別 JSONL は
amb / una とも完全一致、AJIMEE も計測時間 `ms` を除いて全件一致した。
Expected N は既存評価と同じ文全体 n-best による近似である。

実辞書を使う操作記録2件の候補表示期待値も更新した（計7箇所）。
「きかんの」の下位候補「き澗の」は、全0行 RID=1391 の「き」から「澗」へ
つなぐ経路（P=0 のコスト8103）だった。P=3000 でこの経路が下がり、
コスト8412の正規語「季刊の」が9件の候補表示に入る。
期待値は `…気管の, き澗の, 既刊の` から `…気管の, 既刊の, 季刊の` に変更した。
先頭候補、選択・確定内容、キーイベントの期待値は従来どおりである。

全テストは144件、`OK (skipped=2)`。追加の読み込みテスト4件を含め142件成功、
失敗なし。既存の実 LM テスト2件は `OYAYUBI_LM_TESTS` 未設定のためスキップした。
`git diff --check` も成功。
