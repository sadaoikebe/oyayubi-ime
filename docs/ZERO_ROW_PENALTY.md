# 連接表の全 0 行へのペナルティ

## 仕様

`load_lex()` はキャッシュの保存・読み込みとユーザー辞書の適用のあとで、左品詞 RID の連接行が
全列 0 なら、その全列（列 0 の EOS も含む）を 3000 にする。全 0 なので、各連接に +3000 と同じ。
デコーダは変えない。キャッシュは無補正のまま保存する。

`ZERO_ROW_PENALTY=0` で無効、未設定なら 3000。ほかの整数も指定できる（評価用）。環境変数は `load_lex()` の
呼び出しごとに読み、既に読み込まれた辞書には影響しない。

## 確認したこと

全 0 行の RID を持つ辞書エントリには実在語も含まれるので、ペナルティで正しい変換が壊れないかを確かめた。

- [全件一覧（TSV）](zero-row-entries.tsv): 無補正の Mozc 辞書を `load_lex(user_lexicon=False)` で読み、
  全 0 行の RID を持つ全エントリを抜き出したもの（140 行・157 エントリ）。列は RID、`id.def` の品詞、
  読み、表記、LID、単語コスト。省略・重複除去はしていない。BOS の行 0 は全 0 ではない。
  Mozc 辞書の抜粋なので、Mozc 辞書の条件が掛かる（[NOTICE.md](../NOTICE.md)）。
- 全件の読み・表記・品詞を見た。ラ変「あれ・ある・あら・あり」、助動詞「ず」、接尾辞「掛かれ・続け・
  忘れりゃ」、「下・分」、非自立の「はず」、形容詞接尾辞「強けれ・早く・高き・臭え・辛え」、
  接頭詞「第・約」などは文脈次第で正しく使える。旧字体や通常使わない活用、読みの異綴りも混ざる。
- [文例と全出力（TSV）](zero-row-probes.tsv): 手書き辞書あり・学習なし・LM なしで、P=0 と P=3000 の
  1-best を una / amb で比べた 2 組計 284 条件（組の間で重複する文例がある）。ラ変の仮定・命令・未然・
  連用・体言接続、助動詞、接尾動詞の仮定縮約・命令、形容詞接尾辞の各活用、接頭詞、数詞の後の「分」、
  「管理下・支配下」、「はず」などを含む。

| 読み | P=0 → P=3000（una / amb 共通） | 判断 |
|---|---|---|
| あればいい | あればいい → あればいい | 仮定の用例を維持 |
| そうであれ | そうであれ → そうであれ | 命令の用例を維持 |
| ありうるはなし | あり得る話 → ありうる話 | どちらも正しい表記 |
| やくひゃくにん | 約百人 → 約百人 | 全 0 行の RID を避けても同じ表記 |
| わすれりゃいい | 忘れりゃイイ → 忘れりゃイイ | 全 0 行の RID を使ったまま維持 |
| くそったらしけりゃ | クソったらしけりゃ → クソったらしけりゃ | 同上 |

「なだかきひと」（una）は「無高き人→名高き人」、「はずがない」（amb）は「はずえない→はずがない」に
良くなった。「ねだかからぬ」（una）は「ね高からぬ→根高からぬ」に変わったが、元が正しい用例ではない。

**確認した範囲で、正しい変換を誤りに変える例は見つからなかったので、除外する品詞は設けていない。**
「あり得る」の漢字表記を保つ保証はしない。全 157 エントリの全用法を網羅した評価ではない。
評価の外で正しい変換が壊れる例が見つかったら、品詞単位の除外を考える。

## 再現のしかた

- 抽出: `ZERO_ROW_PENALTY=0` で辞書を読み、`not any(lex.connect[rid * lex.pos_size:(rid + 1) * lex.pos_size])`
  で行を選び、`lex.by_reading` の各エントリの `rid` を照合する。
- 文例: TSV の `reading` を使い、una は各文字の plain トークン、amb は
  `yuragi.lattice.table` の `reverse_table(load_table())` の各文字のトークンを `decode_tokens()` に渡す。
  環境変数を 0 / 3000 にして、それぞれ辞書を読み直す。
- 読み込みの単体試験（`tests/test_mozc_dict.py`）は、全 0 でない行が変わらないこと、左 RID の向き、
  EOS への加算、環境変数による無効化、繰り返し読み込みで累積しないこと、キャッシュが無補正のままで
  あることを確かめる。
