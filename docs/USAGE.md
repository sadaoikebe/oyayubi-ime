# ゆらぎの使い方

インストールの1行は [README](../README.md) にあります。この文書は、使い始めたあとに読むものです。

## 打ち方

ゆらぎは、US 配列（ANSI）のキーボードで NICOLA-A の親指シフトを打つ IME です。

親指キーはスペースバーだけです。左の親指か右の親指かは、区別しません。
文字キーとスペースバーを同時に押すと、親指シフトの文字になります。
左右どちらの文字だったかは、変換のときに前後の文脈から決めます。

たとえば「既読」と「記憶」のように、左右の違いで両方とも正しい語になる場合は、
両方を候補に並べます。違う方が出たら、候補から選び直してください。

打っている間も、変換した結果が下線つきで表示されます。
Space を押すと候補窓が出て、候補を選び直せます。

句読点・数字・記号と、Shift を押しながらの英字は、そのまま入ります。

## キー操作

### 入力中（変換する前）

| キー | すること |
|---|---|
| Space（単独で押す） | 変換して、候補窓を出す |
| Enter | 表示のとおりに確定する |
| Backspace | 最後の1打を消す |
| Esc | 入力をすべて消す |
| Tab | 続きの候補を出す（入力の予測）。候補が無ければ、普通の Tab として働く |
| F6〜F10 | 変換してから、下の「変換中」と同じ字種に変える |

### 変換中

| キー | すること |
|---|---|
| Space / ↓ | 次の候補 |
| ↑ | 前の候補 |
| PgDn / PgUp | 候補の次の9件／前の9件 |
| 1〜9 | 候補窓の番号の候補を選ぶ |
| ← / → | 前／次の文節へ移る |
| Shift+← / Shift+→ | 文節を1打ぶん縮める／伸ばす |
| Enter | 全部を確定する |
| そのまま次を打つ | 今の変換を確定して、次の入力に移る |
| Esc / Backspace | 変換をやめて、変換する前の入力に戻る |
| F6 | 今の文節をひらがなにする |
| F7 | 今の文節をカタカナにする |
| F8 | 今の文節を半角カタカナにする |
| F9 | 打ったキーを全角英数にする |
| F10 | 打ったキーを半角英数にする |
| Shift+F6 | 今選んでいる候補の学習を忘れる |
| Shift+F7 | 直前に確定した変換の学習を取り消す（確定した文字はそのまま） |

補足:

- F6 と F7 は、続けて押すと、左右の読み違いのひらがな／カタカナを順に出します。
  左右を取り違えた読みを、ここで直せます。
- F9 と F10 は、続けて押すと、小文字 → 大文字 → 先頭だけ大文字、と変わります。
- Shift+F7 は、何回でも押せます。押すたびに、1つ前の確定の学習を取り消します。

### 直接入力への切り替え

| 操作 | すること |
|---|---|
| `` Alt+` ``（Esc の下、1 の左のキー） | かな入力と直接入力を切り替える |
| タスクバーの「ゆ」「Y」をクリック | 同上 |
| タスクバーの「ゆ」「Y」を右クリック | メニューから切り替える |

ほかの IME との切り替えは Win+Space です。

切り替えのキーは、`%USERPROFILE%\.yuragi-ime\tip.json` で変えられます。
たとえば次のように書きます（`toggle_vk` は Windows の仮想キーコード。192 が ` のキー）。
アプリを開き直すと反映されます。

```json
{"toggle_vk": 192, "toggle_mods": ["alt"]}
```

## 候補窓

変換すると、入力位置の下に候補窓が出ます。

- 1ページに9件まで出ます。番号のキーで選べます。
- 候補の最後には、ひらがなとカタカナの候補もあります。
- 確定した変換は学習され、次から上位に出ます。

## 設定ウィンドウ

タスクバーの「ゆ」「Y」を右クリックして「設定を開く」で開きます。タブは4つあります。

### 単語登録

自分の単語を登録します。読み・単語・品詞を入れて「登録」を押します。
一覧で選んで「選択を削除」で消せます。登録した単語は、次の変換から効きます。

### 学習

学習した内容の一覧です。検索もできます。

- **選択を忘れる**: 選んだ組を、次から上位に出さないようにします（Shift+F6 と同じ）。
- **選択を単語登録**: 選んだ組を単語として登録します。学習を消しても残ります。
- **学習を一時停止／再開**: 一時停止中は、覚えた内容は使いますが、新しくは覚えません。

直前の確定の学習を取り消すのは、キーの Shift+F7 です（上の「変換中」）。

### 設定

設定できる項目が、名前・今の値・説明つきで並んでいます。選んで書き換えるか、「既定に戻す」を押します。
主な項目:

- 学習: 学習する／一時停止／使わない
- 入力の予測: Tab キーで出す／使わない
- 言語モデル: 使う／使わない。使わないときは、辞書だけで変換します

変更は、変換エンジンを再起動すると反映されます（「状態」タブのボタン）。

### 状態

変換エンジンの状態、辞書の照合、学習と登録単語の件数、ファイルの場所を表示します。
「変換エンジンを再起動」のボタンもここにあります。

## 困ったとき

### タスクバーに「!」が出た

日本語変換が止まっています。入力済みの文字は、そのまま残っています。

1. 「!」を右クリックして「**もう一度試す**」を押します。
2. 直らなければ、右クリックの「**原因を表示**」を押します。原因と直し方が出ます。
   - 「必要なファイルが見つからないか、壊れています」: 「入れ直す手順を開く」を押して、
     インストールの1行をもう一度実行してください。学習した内容と登録した単語は残ります。
   - 「辞書の準備ができませんでした」: ディスクの空きを確かめてください（約 300MB 必要です）。
   - 「反応しなくなりました」「繰り返し止まりました」: 「もう一度試す」を押してください。
     「記録のフォルダを開く」で記録（ログ）を見られます。

止まったときは、Windows の通知にも出ます。通知を押しても、原因と直し方が出ます。

### 「止まった」ほどではない知らせ

次の場合は通知だけが出て、変換はそのまま使えます。

| 通知 | 意味 |
|---|---|
| 設定ファイルを読めませんでした | 読めなかった項目は標準の値で動いています。設定ウィンドウの「設定」タブで直せます |
| 言語モデルを使えません | 辞書だけで変換しています。入れ直すと直ることがあります |
| 学習の記録を読めませんでした | 学習なしで動いています。次に起動したとき、もう一度読みます |
| 学習を保存できませんでした | 覚えた内容は、今だけ有効です。ディスクの空きを確かめてください |

### 入力位置の下に出る知らせ

| 知らせ | 意味 |
|---|---|
| 変換の準備をしています… | サインインの直後など。準備ができたら、打った文字が順に入ります |
| 長すぎます。いったん確定してください | 一度に変換できる長さ（200 打）を超えました。それ以上の打鍵は入りません |
| ゆらぎを更新しました。このアプリを開き直すと使えます | 更新の前から開いていたアプリです |

### いつも「Y」のまま

管理者として動いているアプリなど、一部のアプリでは日本語変換を使えません。
そのアプリでは「Y」のままで、英字がそのまま入ります。

## 更新

インストールと同じ1行を、もう一度実行します（[README](../README.md)）。

- アプリは開いたままで構いません。
- 取得するのは、変わったものだけです。
- 途中で失敗しても、それまでの版がそのまま動きます。もう一度実行すると、続きから進みます。
- 学習した内容・登録した単語・設定は、そのまま引き継ぎます。
- 更新の前から開いていたアプリでは「このアプリを開き直すと使えます」と出ることがあります。
  そのアプリを開き直してください。
- 旧名（oyayubi-ime）の版から更新すると、`%USERPROFILE%\.oyayubi-ime` の中身を
  `%USERPROFILE%\.yuragi-ime` へ移します。旧い方は消しません。

## アンインストール

[README](../README.md) の1行を実行します。入っている版は自動で見つけます。

- 管理者の確認が1回出ます。アプリは開いたままで構いません。
- 使用中で消せなかったファイルは、次に Windows を起動したときに自動で消えます。
- 学習した内容・登録した単語・設定（`%USERPROFILE%\.yuragi-ime`）は残ります。
- これらも消すときは、1行の末尾に ` -RemoveData` を付けます。消す前に、場所と大きさを表示して確かめます。
- 入っていない PC で実行すると、「入っていません」と表示して終わります。
- 途中で止まったとき（管理者の確認を取り消したときなど）は、もう一度実行すると続きから進みます。

置き場所と手順の細かいところは [INSTALL.md](INSTALL.md) にあります。

## データの置き場所

| 場所 | 中身 |
|---|---|
| `%USERPROFILE%\.yuragi-ime\` | 学習した内容、登録した単語、設定、記録（ログ） |
| `%LOCALAPPDATA%\yuragi-ime\` | 変換のプログラム、辞書、言語モデル |
| `%ProgramFiles%\yuragi-ime\` | アプリに読み込まれる部分 |
